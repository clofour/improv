# Go Crash Course

Before getting started, install Go from [the Go website](https://go.dev/dl/) and the Go plugin for your editor, if one exists.

## Tooling

The Go binary comes with multiple commands.
|Command|Description|
|---|---|
|`go mod init github.com/example/example`|Start a new project|
|`go run .`|Compile and run the program|
|`go build -o hello.exe .`|It does something|
